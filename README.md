# 웹 코더

백준(BOJ) 제출 페이지에서 코드를 작성하고, 테스트를 실행하고, 바로 제출까지 할 수 있는 크롬 확장 프로그램입니다.

별도의 IDE 없이도 브라우저 안에서 편리하게 문제를 풀어 볼 수 있습니다.

## 핵심 기능

- **에디터 자동 렌더링** — BOJ 제출 페이지(`/submit`)를 열면 커스텀 에디터가 자동으로 나타납니다.
- **다양한 언어 지원** — C++, Java, Python, Rust로 코드를 작성하고 테스트할 수 있습니다.
- **실행 백엔드 자동 선택** — 언어에 따라 가장 적합한 실행 환경이 자동으로 결정됩니다.
  - C++ / Python: 로컬 WebAssembly로 빠르게 실행됩니다.
  - Rust / Java: Piston API를 통해 실행됩니다.
- **기존 제출 흐름 그대로** — BOJ의 `제출` 버튼과 자연스럽게 연동됩니다.
- **설정 없이 바로 사용** — 외부 API 키 등 추가 설정 없이 설치 후 곧바로 사용할 수 있습니다.
- **설정 자동 저장** — 기본 언어, 코드, 테스트 케이스, 테마 등 사용자 설정이 로컬에 자동 저장됩니다.

## 지원 언어

| BOJ 언어 ID | 언어 | 내부 실행 키 | 실행 백엔드 |
| --- | --- | --- | --- |
| `84` | C++17 | `cpp17` | 로컬 WebAssembly |
| `93` | Java 11 | `java` | Piston API |
| `28` | Python 3 | `python3` | 로컬 WebAssembly |
| `116` | Rust 2024 | `rust` | Piston API |

## 실행 방식

코드 실행은 언어에 따라 두 가지 방식으로 이루어집니다.

- **C++ / Python**은 확장 프로그램에 내장된 WASM 런타임에서 실행됩니다. 외부 서버를 거치지 않으므로 빠르고 안정적입니다.
- **Rust / Java**는 [Piston API](https://emkc.org/api/v2/piston/execute)를 통해 실행됩니다.
- 실행 결과는 background service worker에서 처리된 뒤 테스트 패널에 표시됩니다.

## 시작하기

아래 명령어로 프로젝트를 빌드합니다.

```bash
npm install
npm run build
```

빌드가 완료되면 Chrome에 확장 프로그램을 등록합니다.

1. `chrome://extensions` 페이지에 접속합니다.
2. 우측 상단의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** 버튼을 클릭합니다.
4. 이 프로젝트의 `dist` 폴더를 선택합니다.

등록이 완료되면 BOJ 제출 페이지에서 웹 코더를 바로 사용할 수 있습니다.

## 팝업 안내

1. 브라우저 툴바에서 확장 아이콘을 클릭합니다.
2. 실행 방식에 대한 안내 문구를 확인할 수 있습니다. 별도의 키 입력은 필요하지 않습니다.
3. BOJ 제출 페이지에서 `실행` 버튼을 눌러 코드를 테스트합니다.
4. 동작이 이전 상태로 보일 경우, 확장 프로그램을 다시 로드한 뒤 BOJ 탭을 새로고침해 주세요.
