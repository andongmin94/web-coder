# Chrome 웹 스토어 등록 자료

## 패키지

```powershell
npm run package
```

`node build.ts`로 빌드한 뒤 `release/web-coder-<버전>.zip`을 만듭니다. 이 zip을 개발자 대시보드에 올립니다.
설치 후 용량은 약 57MB입니다. 큰 컴파일러 파일은 gzip으로 담고, 처음 컴파일할 때 풀어 씁니다.

## 기본 정보

- 이름: 웹 코더
- 요약 (132자 이하): 백준 제출 페이지에서 바로 실행하고 제출하는 로컬 코드 에디터
- 카테고리: 개발자 도구
- 언어: 한국어

## 상세 설명

백준 온라인 저지(acmicpc.net)에서 문제를 보면서 코드를 쓰고, 예제를 바로 돌려 보고, 그대로 제출하세요.

■ 내 컴퓨터에서 바로 실행

- C++ (clang, C++98~C++26), Python 3 / PyPy3, node.js, Java를 브라우저 안에서 컴파일하고 실행합니다.
- 서버로 코드를 보내지 않으니 빠르고, 코드가 밖으로 나가지 않습니다.
- 예제 입출력을 자동으로 불러와 한 번에 채점하고, 틀린 줄을 표시해 줍니다.
- 직접 만든 테스트 케이스를 추가할 수 있습니다.

■ 언어별 자동 완성과 오류 표시

- C++: clang 기반 멤버 자동 완성과 실시간 컴파일 오류
- Python: Pyright 기반 자동 완성, 타입 오류, 오타 표시
- node.js: TypeScript 언어 서비스 기반 자동 완성
- Java: JDK 클래스 자동 완성, 생성자·메서드 시그니처 힌트, 컴파일 오류

■ 그대로 제출

- 문제 메뉴의 "웹 코더로 제출" 탭을 누르면 에디터가 열립니다.
- 제출 버튼을 누르면 백준 제출 폼으로 제출합니다.

■ 편의 기능

- 에디터 테마 43종, 다크 모드, 글자 크기 조절
- 문제별·언어별 코드 자동 저장
- 깊은 재귀와 C++ 예외 지원

## 개인정보 보호 탭

- 단일 목적: 백준 온라인 저지에서 코드를 작성하고 로컬에서 실행한 뒤 제출하도록 돕는 에디터를 제공합니다.
- `storage` 권한 사유: 문제별로 작성 중인 코드, 사용자가 추가한 테스트 케이스, 문제 예제 캐시, 에디터 설정을 브라우저에 저장합니다.
- 호스트 권한 사유 (acmicpc.net): 백준 문제 페이지에 "웹 코더로 제출" 탭을, 제출 페이지에 에디터를 표시하고, 사용자가 제출을 누르면 백준 제출 폼에 코드를 채워 제출합니다.
- 원격 코드 사용: 아니요. 컴파일러와 런타임(WebAssembly)은 모두 패키지에 포함되어 있습니다.
- 데이터 사용: 어떤 사용자 데이터도 수집하거나 전송하지 않습니다. (모든 항목 체크하지 않음)
- 개인정보처리방침 URL: `docs/store/privacy.md`를 공개 URL로 올린 뒤 그 주소를 적습니다. (예: GitHub 저장소의 파일 주소)
