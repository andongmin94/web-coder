# 웹 코더 개인정보처리방침

최종 수정: 2026-11-23

웹 코더(이하 "확장")는 백준 온라인 저지(acmicpc.net)의 문제 페이지와 제출 페이지에서 코드를 작성하고, 내 컴퓨터 안에서 예제를 실행해 보고, 백준 제출 폼으로 제출하도록 돕는 Chrome 확장 프로그램입니다.

## 수집하는 정보

확장은 개인정보를 수집하지 않으며, 개발자나 제3자의 서버로 어떤 데이터도 보내지 않습니다.

## 브라우저 안에만 저장하는 정보

다음 정보는 `chrome.storage.local`(이 브라우저의 확장 저장소)에만 저장되고 밖으로 나가지 않습니다.

- 문제별·언어별로 작성 중인 코드
- 직접 추가한 테스트 케이스
- 문제 본문과 예제 (문제 페이지를 열 때 화면에 이미 받은 내용을 보관)
- 에디터 설정 (언어, 테마, 글자 크기, 패널 크기 등)

또 C++ 컴파일 속도를 높이려고 미리 컴파일한 헤더를 브라우저의 IndexedDB에 보관합니다.

이 정보는 확장을 삭제하면 함께 지워집니다.

## 네트워크 사용

- 코드 실행, 컴파일, 자동 완성은 확장에 포함된 WebAssembly 런타임으로 모두 내 컴퓨터 안에서 처리합니다. 코드를 외부 서버로 보내 실행하지 않습니다.
- 확장이 직접 요청하는 곳은 백준(acmicpc.net)뿐입니다. 문제 본문이 캐시에 없을 때 문제 페이지를 다시 읽어 옵니다.
- 사용자가 "제출"을 누르면 백준이 제공하는 제출 폼에 코드를 채워 백준에 제출합니다. 이것은 사용자가 백준에서 직접 제출하는 것과 같으며, 백준의 개인정보처리방침을 따릅니다.

## 권한

- `storage`: 위의 코드, 테스트, 설정을 저장합니다.
- acmicpc.net 페이지 접근: 문제 페이지와 제출 페이지에 에디터와 "웹 코더로 제출" 탭을 붙입니다.
