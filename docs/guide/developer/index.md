# 개발자 시작하기

이 영역은 웹 코더를 수정하거나 유지보수하려는 개발자를 위한 문서입니다.

사용자 입장에서는 대부분 필요하지 않고, 소스 구조나 로컬 빌드가 궁금할 때 보면 됩니다.

## 이 문서에서 다루는 내용

- [로컬 개발 및 빌드](./setup.md) — 레포를 설치하고 Chrome에 직접 로드하는 방법
- [기술 구조](./architecture.md) — 확장 내부 흐름과 주요 파일 구조

## 빠른 안내

- 일반 사용자는 [사용자 문서](/guide/user/)부터 보는 것이 맞습니다.
- 개발자는 `packages` 폴더에서 확장을 빌드합니다.
- 문서 사이트는 `docs` 폴더의 VitePress 프로젝트로 관리합니다.

## 저장소 구성

| 경로 | 설명 |
| --- | --- |
| `packages/` | 실제 Chrome 확장 소스 코드 |
| `docs/` | 사용자 문서와 개발자 문서를 함께 제공하는 VitePress 사이트 |
