# 설치 및 빌드

웹 코더는 소스 코드를 직접 빌드한 뒤 Chrome에 로드하는 방식으로 설치합니다.

아래 단계를 차례로 따라 하면 금방 끝나니 걱정하지 마세요!

## 1) 의존성 설치

먼저 레포 루트에서 `packages` 폴더로 이동한 뒤, 필요한 패키지를 설치해 주세요.

```bash
cd packages
npm install
```

## 2) 확장 빌드

패키지 설치가 끝났다면 빌드 명령어를 실행해 주세요.

```bash
npm run build
```

빌드가 완료되면 `packages/dist` 폴더에 결과물이 생성됩니다.

## 3) Chrome에 로드

빌드된 확장을 Chrome에 직접 로드해 보겠습니다.

1. Chrome 주소창에 `chrome://extensions`를 입력해서 확장 관리 페이지에 들어가세요.
2. 우측 상단의 **개발자 모드** 토글을 켜 주세요.
3. **압축해제된 확장 프로그램을 로드** 버튼을 클릭하세요.
4. 방금 생성된 `packages/dist` 폴더를 선택하면 끝입니다!

::: tip 코드를 수정했을 때
코드를 수정한 뒤에는 `npm run build`를 다시 실행하고, 확장 관리 페이지에서 웹 코더의 **새로고침** 아이콘을 클릭해 주세요. 그 다음 BOJ 탭도 새로고침하면 변경 사항이 반영됩니다.
:::

## 4) 팝업 확인 (선택)

별도의 API 키 설정은 필요하지 않습니다. 확장 아이콘을 클릭하면 나타나는 팝업에서는 현재 실행 방식 안내를 간단히 확인할 수 있습니다.

::: warning 동작이 반영되지 않을 때
확장을 업데이트했는데 이전 상태로 보인다면, 확장 프로그램을 다시 로드하고 BOJ 탭을 새로고침해 보세요.
:::
