# 설치

이 페이지는 일반 사용자가 웹 코더를 바로 설치하고 사용하는 방법을 안내합니다.

직접 소스를 빌드하려는 경우에는 [개발자 문서](/guide/developer/setup)를 참고해 주세요.

## 1) Chrome 웹 스토어에서 설치

가장 쉬운 방법은 Chrome 웹 스토어에서 확장을 설치하는 것입니다.

- [웹 코더 Chrome 웹 스토어 바로가기](https://chromewebstore.google.com/detail/banebmcldnjjliapeiaobcfodgcbhfcl?utm_source=item-share-cb)

설치가 끝나면 Chrome 툴바에 웹 코더 아이콘이 나타납니다.

## 2) BOJ 제출 페이지 열기

웹 코더는 BOJ의 `/submit` 경로에서 동작합니다.

- `https://www.acmicpc.net/submit/...`
- `https://boj.kr/submit/...`

해당 페이지에 들어가면 기본 제출 폼 대신 웹 코더 화면이 자동으로 나타납니다.

## 3) 팝업 확인

확장 아이콘을 클릭하면 현재 빌드가 **C++17과 Python 3을 로컬에서 실행한다**는 안내를 볼 수 있습니다.

별도의 API 키나 서버 설정은 필요하지 않습니다.

## 4) 화면이 바로 안 바뀔 때

설치 직후나 업데이트 직후에 이전 화면이 보이면 아래 순서로 다시 확인해 주세요.

1. `chrome://extensions`에서 웹 코더가 활성화되어 있는지 확인합니다.
2. BOJ 탭을 새로고침합니다.
3. 그래도 같다면 Chrome 자체를 한 번 더 새로고침하거나 탭을 다시 엽니다.
