# 시작하기

**웹 코더(Web Coder)** 는 백준(BOJ) 제출 페이지를 더 편리하게 바꿔 주는 Chrome 확장 프로그램입니다.

기존 제출 폼 대신 **코딩·테스트·제출을 한 화면에서 끝낼 수 있는 커스텀 UI**가 자동으로 나타납니다.

웹 코더가 있으면 이런 것들을 한 곳에서 할 수 있습니다.

- **문제 본문**을 왼쪽 패널에서 바로 확인
- **코드 작성** — 문법 하이라이팅이 적용된 에디터에서 곧바로 코딩
- **테스트 케이스 실행** — 샘플 입출력은 물론, 직접 만든 커스텀 테스트도 실행
- **BOJ 제출** — 버튼 하나로 백준에 바로 제출

## 지원 환경

웹 코더는 **Chrome Manifest V3** 확장으로 동작합니다.

- **브라우저**: Chrome (Manifest V3)
- **대상 페이지**: `https://www.acmicpc.net/*`, `https://boj.kr/*`
- **동작 경로**: `/submit` 접두 경로에서만 커스텀 UI가 활성화됩니다 (`/submit`, `/submit/<problemId>/<submissionId>` 포함)

## 지원 언어

현재 웹 코더에서 코드를 실행하고 제출할 수 있는 언어는 다음과 같습니다.

| BOJ 언어 ID | 언어 | 내부 실행 키 | 실행 백엔드 |
| --- | --- | --- | --- |
| `84` | C++17 | `cpp17` | 로컬 WebAssembly |
| `28` | Python 3 | `python3` | 로컬 WebAssembly |

실제 드롭다운에는 해당 문제의 BOJ 제출 폼에 존재하는 언어 중 확장이 지원하는 항목만 표시됩니다. 예를 들어 특정 문제가 Python만 허용한다면, 드롭다운에도 Python 3만 나타나게 됩니다.
