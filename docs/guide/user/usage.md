# 사용 가이드

웹 코더를 설치했다면, 이제 실제로 문제를 풀어 볼 차례입니다.

이 페이지에서는 화면 구성부터 테스트·제출까지 전체 흐름을 안내합니다.

## 기본 동작

확장이 활성화된 상태에서 BOJ 제출 페이지(`/submit`)에 진입하면, 기존 제출 폼은 자동으로 숨겨지고 **커스텀 분할 화면**이 나타납니다.

**화면 구성**

- **좌측** — 문제 본문이 표시됩니다.
- **우측 상단** — 코드 에디터입니다.
- **우측 하단** — 테스트 실행 결과가 표시됩니다.

## 상단 컨트롤

화면 상단에는 제출 옵션과 언어 설정이 모여 있습니다.

- **코드 공개** — 공개 / 비공개 / 맞았을 때만 공개 중 원하는 설정을 선택할 수 있습니다.
- **언어** — C++17과 Python 3 중 해당 문제에서 제출 가능한 언어만 드롭다운에 표시됩니다.
- **현재 언어를 기본값으로 설정** — 자주 쓰는 언어를 기본값으로 지정할 수 있습니다.
- **기본 BOJ 제출 폼으로 전환** — 웹 코더 화면을 닫고 백준 원래 제출 폼으로 돌아갈 수 있습니다.

## 하단 버튼

화면 하단에는 코딩과 제출을 위한 주요 버튼들이 배치되어 있습니다.

- **초기화** — 현재 선택된 언어의 기본 템플릿으로 에디터를 초기화합니다.
- **공식 문서** — 현재 언어의 레퍼런스 문서를 새 탭에서 엽니다.
- **테스트 케이스 추가** — 최대 10개까지 커스텀 테스트 케이스를 입력할 수 있습니다.
- **실행** — 작성한 코드를 테스트 케이스로 실행합니다. C++17과 Python 3은 모두 로컬 WebAssembly로 실행됩니다.
- **제출** — BOJ에 코드를 제출합니다.

::: tip 언어 자동 전환
제출 시 현재 선택된 언어가 해당 문제에서 비활성화되어 있으면, 제출 가능한 지원 언어로 자동 전환한 뒤 안내 메시지를 보여 줍니다.
:::

## 테스트 케이스

테스트 케이스는 제출 전에 결과를 확인하는 핵심 기능입니다.

- 문제 페이지의 **샘플 입력/출력**은 자동으로 파싱되어 미리 채워집니다.
- **커스텀 테스트 케이스**는 모달 창에서 자유롭게 추가·삭제·저장할 수 있습니다.
- 실행 후에는 **실행 결과**, **출력**, **기댓값**을 한눈에 비교할 수 있습니다.
- 특수 채점(SPJ) 문제의 경우에는 정답/오답 비교 대신 실제 출력 내용을 그대로 보여 줍니다.

## 수정 제출

수정 제출 경로로 들어오면 웹 코더가 기존 소스 코드를 자동으로 불러옵니다.

복원 과정은 다음과 같이 진행됩니다.

1. 제출 ID를 추적해서 기존 소스 코드를 찾습니다.
2. URL 파라미터 → 폼 필드 → 소스 링크 순서로 코드를 탐색합니다.
3. 필요하면 `/source/<id>` 계열 URL을 다시 요청해서 코드를 가져옵니다.

::: info 코드가 바로 안 보여도 걱정하지 마세요
코드 복원이 약간 지연될 수 있습니다. 잠시 기다리면 코드가 자동으로 채워집니다.
:::
