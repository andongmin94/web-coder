# 문제 해결

사용 중에 잘 안 되는 상황이 생기면 아래 항목부터 확인해 보세요.

## `실행` 버튼을 눌렀는데 오류가 나옵니다

실행 오류는 보통 아래 원인 중 하나입니다.

- **코드 자체의 문제** — 컴파일 에러나 런타임 에러일 수 있습니다.
- **확장 새로고침 필요** — 업데이트 뒤에 이전 버전이 남아 있을 수 있습니다.

::: tip 이렇게 해 보세요
1. 확장 프로그램을 다시 로드하고 BOJ 탭을 새로고침해 주세요.
2. 다시 **실행**을 눌러 출력 메시지(컴파일 에러 / 런타임 에러)를 확인해 보세요.
3. 같은 코드가 계속 실패하면, 문제의 샘플 입력으로 먼저 다시 확인해 보세요.
:::

## 제출이 실패합니다

제출 실패는 보통 세션이나 네트워크 문제일 가능성이 높습니다.

- **BOJ 세션 만료** — 로그인 상태가 끊겼을 수 있습니다.
- **Cloudflare 토큰 만료** — `cf-turnstile-response` 토큰이 만료되면 제출이 거부될 수 있습니다.
- **일시적인 네트워크 문제** — BOJ 서버나 네트워크 상태가 불안정할 수 있습니다.

::: tip 이렇게 해 보세요
1. 페이지를 새로고침한 뒤 다시 제출해 보세요.
2. BOJ에 로그인되어 있는지 다시 확인해 주세요.
3. 같은 문제가 반복되면 브라우저 콘솔(`F12` → Console 탭) 메시지를 확인해 보세요.
:::

## 원하는 언어가 선택 목록에 보이지 않습니다

웹 코더는 현재 다음 두 가지 BOJ 언어만 지원하고 있습니다.

- `84` (C++17)
- `28` (Python 3)

드롭다운 목록은 BOJ 제출 폼에 실제로 노출된 언어와 동기화되기 때문에, 지원 언어라도 문제 조건에 따라 보이지 않을 수 있습니다.

::: tip 이렇게 해 보세요
1. 먼저 해당 문제의 BOJ 기본 제출 폼에서 실제로 제출 가능한 언어를 확인해 주세요.
2. 지원하지 않는 언어로 제출해야 한다면, 상단의 **기본 BOJ 제출 폼으로 전환** 버튼을 눌러 원본 폼에서 제출할 수 있습니다.
3. 목록이 이상하다면, 확장 재로드 후 BOJ 탭을 새로고침해 보세요.
:::

## 수정 제출에서 코드가 비어 보입니다

수정 제출(`/submit/<problemId>/<submissionId>`) 경로로 들어왔을 때 에디터가 비어 있더라도 걱정하지 마세요.

웹 코더가 URL 파라미터, 폼 필드, `/source/<id>` 링크 등을 통해 원본 코드를 복원하고 있는 중일 수 있습니다.

복원에 약간의 시간이 걸릴 수 있어서, 페이지 진입 직후에는 빈 화면이 보일 수 있습니다.

## 테마·코드·테스트 케이스가 유지되지 않습니다

웹 코더의 저장 데이터는 `chrome.storage.local`에 보관됩니다.

다음과 같은 경우에는 저장된 데이터가 사라질 수 있습니다.

- 브라우저의 데이터 정리 정책에 의해 자동 삭제된 경우
- 확장을 재설치한 경우
- 다른 Chrome 프로필에서 접속한 경우

::: warning
중요한 코드는 별도로 백업해 두는 것을 권장합니다.
:::
