# 개인정보처리방침

웹 코더는 여러분의 개인정보를 소중히 생각합니다. 수집하거나 판매하는 일은 절대 없습니다.

이 문서에서는 웹 코더 확장 프로그램이 데이터를 어떻게 다루는지 알려드리겠습니다.

## 수집하는 정보

웹 코더는 이름, 이메일, 전화번호 같은 개인정보를 일절 수집하지 않습니다.

다만, 확장 프로그램이 정상적으로 동작하기 위해 아래 정보가 브라우저 로컬 저장소(`chrome.storage.local`)에 저장될 수 있습니다.

## 로컬에 저장되는 정보

다음 항목들은 오직 여러분의 브라우저 안에만 보관됩니다.

- 언어 설정, 코드(문제별·제출 단위), 커스텀 테스트 케이스
- 에디터 테마 및 기본 언어

이 정보는 여러분의 브라우저 로컬 환경에만 저장되며, 웹 코더 제작자가 별도 서버로 수집하지 않습니다. 안심하세요!

## 외부로 전송되는 경우

아래 상황에서만 여러분이 입력한 내용이 외부로 전송됩니다.

- **실행** 버튼을 클릭했을 때
  - C++17 / Python 3: 로컬 WebAssembly로 실행되므로 외부 전송이 없습니다.
- **제출** 버튼을 클릭했을 때
  - 코드, 언어, 제출 옵션이 BOJ 제출 엔드포인트로 전송됩니다.

그 외에는 어떤 데이터도 외부로 나가지 않습니다.

## 제3자 제공

웹 코더 제작자가 별도로 제3자에게 데이터를 제공하는 일은 없습니다.

다만, 여러분이 직접 **제출** 버튼을 눌러 요청한 경우에는 BOJ의 자체 개인정보처리방침이 적용됩니다. 이 점 참고해 주세요.
